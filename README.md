Welcome to Owlowgy!
This is a project intendent to help school students to find a perfect tutor according to their personality type
At current state, project has a registartion page for teachers and students (there are two separeate pages for them, personality test, and student-tutor matching system with simple AI-like logic)
The project can save data about user(like their name, desired grade, personality type) save sessions of a user , track current time, and match appropriate student/teacher.
Used technologies: (HTML-for web elements, JavaScript-to make project interactive, PHP to create connection with database and for some interactive elements, SQL for database
